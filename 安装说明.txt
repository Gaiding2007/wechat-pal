微信聊天伴侣 wechat-pal · 安装说明
====================================

一、安装
1. 下载 `wechat-pal-setup-3.3.0.exe`，双击运行。
2. 安装程序默认装到：
   %LOCALAPPDATA%\Programs\wechat-pal
   可以点「浏览」改成别的目录；不需要管理员权限。
3. 勾选「创建桌面快捷方式」，装完桌面会有「微信聊天伴侣」。
4. 安装后自动打开网页控制台：http://127.0.0.1:8787

（如果没有安装包，也可以解压 zip 后双击「启动微信聊天伴侣.bat」直接运行。）

二、第一次使用
1. 网页「设置 → 模型服务」里填 DeepSeek（或其他 OpenAI 兼容服务）的 API Key。
2. 不填 Key 也能用：会进入演示模式，回复是固定的几句话。
3. 想连真实微信：
   - 先在电脑上登录微信 4.x（建议小号），主窗口停在聊天列表；
   - 回到安装目录，双击「启动微信桥接.bat」；
   - 看到「当前登录账号 / 数据库目录 / 开始监听新消息」就成功了。
4. 语音识别、生图、看图是可选能力，各自的 Key 在设置页单独填。

三、升级
直接运行新版本的安装包覆盖安装即可，data 文件夹里的聊天记录、人设、立绘和设置会保留。

四、卸载
1. 关闭「微信聊天伴侣」和「微信桥接」两个窗口。
2. Windows「设置 → 应用 → 已安装的应用」里卸载「微信聊天伴侣」。
3. 聊天记录在 data 里，卸载前可先备份。

五、常见问题
- 桥接提示「微信主程序没有运行」：先打开微信并登录，再启动桥接。
- 桥接提示「低完整性」：右键「修复权限.bat」以普通方式运行一次；安装包已自动修复。
- 发送/点赞/评论需要正常桌面：远程桌面锁屏、无桌面会话里 UIA 不可用。
- 朋友圈图片显示「图片未缓存」：先在微信里点开任意一张图看大图，停几秒，再回来点加载。
- 表情包识别仍不准：新版会截图看画面，动图抽 3 帧；识别结果缓存在 data/sticker-desc.json，第二次会快很多。
