怎么启动桥接
  1. 先打开微信主程序（Weixin.exe）并完成登录，主窗口停在聊天列表（可以最小化到任务栏，别退出）
  2. 双击根目录的 启动微信桥接.bat，它会自动找微信和数据库
  3. 连上后命令行会打出账号和数据库路径；让别人发消息，就会自动回，这里状态变成「已连接」

Python 和依赖已经打包在 runtime/ 里，不用另外装。桥接通过模拟操作微信窗口工作，建议用小号。

生图

让她学会画图：对话里说「画一张…」或到「表情」页点「生成图片」。用的是通义千问 qwen-image-3.0，需要一个 DashScope / 千问 Key；生成结果存在 data/stickers/，会自动按图片发到微信。

启用生图 关闭后不会调用生图接口
和看图 Key 不是一回事；不填则不能生图。

语音识别

和开源项目一样，用通义千问 qwen3-asr-flash 把语音转成文字；微信 4.x 的「语音转文字」是本地界面行为，数据库和 UIA 都读不到，只能走外部识别。

识别语音 关闭后收到语音只回「没听清」，不做转写
不填则不会转写；DeepSeek 的 Key 不能用于语音。
