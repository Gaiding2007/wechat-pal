# wechat-pal · 微信聊天伴侣

一个**可以换人格**的微信 AI 搭子，也是一套能直接操作你微信的控制台。网页里可以直接聊，也可以接到自己的微信上；除了文字，还能看微信里的真实会话、图片、语音和文件，浏览朋友圈、点赞评论，管理表情库，以及看她自己的「生活」状态。

名字叫 `wechat-pal`，显示名「微信聊天伴侣」。默认带两套人格：

- **鲸鱼娘**：蓝发、鲸尾、嘴上说「别摸头」，其实会记住你随口提过的小事；喜欢吃白米饭，偶尔念一句「探索未至之境」。
- **贴吧吧友**：老吧友口气，先给结论再讲道理，阴阳归阴阳，你认真求助的时候他会收起玩梗。

> 鲸鱼娘是同人角色，性格参考 B 站上的社区二创，不是官方设定；贴吧预设参考了早期开源项目的人设写法，但去掉了脏话和人身攻击。

## 3.3 更新

- **真正的安装包**：`wechat-pal-setup-3.3.1.exe`，双击安装，可自定义目录，装完桌面有快捷方式。不再需要解压 zip。
- **角色立绘 / 自拍**：鲸鱼娘重新做了全身立绘（透明底，`assets/persona/whale-girl.png`）和 Q 版形象（`assets/persona/whale-girl-chibi-cutout.png`），网页图标、安装包图标、封面统一。在聊天里说「发张自拍」「看看你长什么样」，她会发自己的图，而不是随便生成一个陌生人。人设页可维护多张 `selfies`。
- **表情包识别**：不再只靠表情名。会先截图聊天区做视觉识别；动图按 2fps 抽 3 帧逐帧描述再合并。识别结果缓存在 `data/sticker-desc.json`，第二次 0 秒。认不出时会诚实说「没看清」，不瞎编。
- **介绍视频**：`dist/wechat-pal-intro.mp4`，约 56 秒，lemo-opuscar 的 Dark Tech Keynote 风格（暗色舞台、荧光绿强调、UI 当主角），Edge TTS 晓伊配音，字幕跟旁白；人声出现时 BGM 自动压低。新增「自定义人格」和「微信里回文字/图片」演示。封面 `dist/bilibili-cover.png`，投稿文案 `dist/bilibili.txt`，分镜见 `docs/B站视频故事板.md`。
- **图片发送**：确认过了，桥接本来就是「把文件放进剪贴板 → 在输入框 Ctrl+V → 发送」，不经过桌面。之前看到的路径只是临时文件。
- **语音**：保持 3.2 的结论——微信内置转文字没有可编程入口；开源项目也是外部 DashScope ASR。设置里可填 Key，不填就回「没听清」。

## 3.2 更新

- **群聊回复对象**：会先看这句话是谁说的，只回这个人；如果对方转述「老大说了什么」，会明确说「这是老大说的，你去问他准」，不替不在场的人编。
- **表情包 + 追问**：处理图片/表情时如果又来了「这是谁」这类新消息，旧回复会作废，按新消息接，不再答非所问。
- **表情包识别**：强制截图/视觉识别；动图按 2fps 抽 3 帧逐帧描述再合并，避免只认第一帧。识别结果缓存在 `data/sticker-desc.json`，第二次 0 秒。
- **生图**：设置 → 生图里填 DashScope / 千问的 Key 后，可以在聊天里说「画一张…」，或在表情页点「生成图片」。生成结果存 `data/stickers/gen-*.png`，会作为图片发到微信。识图不会误调生图，只有明确画图指令才调用。
- **语音**：微信 4.x 的「语音转文字」是本地自绘界面，数据库和 UIA 都没有可编程入口。开源项目实际也是用外部 ASR（DashScope `qwen3-asr-flash`），不是微信内置。本版恢复「设置 → 语音识别」分区，填 Key 后启用；没填时回「没听清，你打两个字？」。
- **转发视频链接**：桥接能读出卡片里的标题和 `<url>`；如果微信转发卡片本身不带 `<url>`，就只能看到标题，读不到视频内容。B 站链接会额外抓标题/UP/简介/字幕。

## 为什么是它

- **人设功能是完整的**：不止一个名字和一句简介。年龄、身份、外貌、性格、说话风格、兴趣、边界、口头禅、开场白、快捷话题、文风预设、表情浓度、主动程度、主见程度、额外规则、主人绑定，都能改；配置页 `/persona` 可以导入/导出 JSON、套用预设、恢复默认。
- **接微信是开箱即用的**：不用装 Python，不用 `pip install`，也不用改环境变量。双击「启动微信桥接.bat」，它自带运行时，会自动找本机登录的微信 4.x；微信还没登录就每 5 秒重试，登录后自动连上，命令行会显示账号和数据库目录。
- **功能没被砍**：私聊、群聊 @、多气泡、记忆、主动搭话、群聊静默/冷却、图片理解、B 站分享、调试台、热键暂停，都还在。
- **微信控制台**：左侧「微信消息」直接读本机微信的真实会话与聊天记录，能看图片、听语音、打开文件，也能以你的身份发文字、图片、文件。
- **朋友圈**：读得到真实动态、点赞和评论；发布是实验性的，微信 4.x 没有稳定接口，界面会如实说明。
- **表情与「生活」**：表情库存自己上传/收集的图，点一下就发到当前微信会话；「生活」页有心情、精力、亲近度和今日计划，聊天会真的影响她的状态。
- **UI 是简洁的**：纸张底色 + 墨绿强调色，左边导航，中间内容；手机上侧栏收成抽屉，底部有五个入口。没有花哨皮肤，但该有的开关一个不少。

## 快速开始

从 [GitHub Releases](https://github.com/Gaiding2007/wechat-pal/releases) 下载 **`wechat-pal-setup-3.3.1.exe`**，双击安装（可以改安装目录），装完桌面会有「微信聊天伴侣」快捷方式。也可以直接双击 **`启动微信聊天伴侣.bat`**，浏览器会自动打开 <http://127.0.0.1:8787>。包内自带 Node，不需要另装。

也可以手动启动：

```bash
node server.js
```

第一次打开是**演示模式**：没填 API Key 时用几句固定的中文回复，把界面和流程先走通；顶部会明确标着「演示模式」，不会假装是真的模型。

### 填一个模型

右上角「设置」→「模型服务」：

| 服务商 | 说明 |
| --- | --- |
| DeepSeek | 默认，中文口语自然，按量计费 |
| 智谱 GLM | 有免费额度 |
| 通义千问 | 阿里云百炼的 OpenAI 兼容接口 |
| SiliconFlow | 聚合开源模型，常有免费额度 |
| Ollama | 本机跑，不用 Key |
| 自定义 | 任何 OpenAI 兼容接口 |

Key 只保存在本机 `data/settings.json`，不会上传到别处。设置页会铺满整个对话区，保存 / 测试 / 清除 Key 固定在底部，不用滚到中间找。填完点「保存」，再点「测试连接」确认能通。

## 人设

### 两套预设

| 预设 | 她/他是什么样 | 适合 |
| --- | --- | --- |
| 鲸鱼娘 | 傲娇、天然呆、想很多、干饭魂；会损你两句，但不会真的刻薄 | 想要一个有点角色感、又不会端着说话的对象 |
| 贴吧吧友 | 老吧友，先给结论、爱抬杠、反矫情，认真求助时会收起玩梗 | 想要一个说人话、不哄人的聊天对象 |

在设置抽屉的「人设」里切换，或者打开 `http://127.0.0.1:8787/persona`（也可以双击 `编辑人设.bat`）。

### 人设配置页

- 左边是预设列表和实时预览，右边按「基本 / 性格与说话 / 关系与偏好 / 高级提示词」分组。
- 所有字段都会进系统提示词；「额外规则」是最后追加的自由文本，适合写角色专属的口头禅和禁忌。
- 「导入 JSON」吃下面这种结构；「导出」会下载当前人设；「恢复预设」只改当前人设，不会动预设文件。
- 保存后写入 `data/persona.json`。微信桥接每次启动也会读这个文件，所以网页里改完名字/别名/主人，桥接会自动用新的。

```json
{
  "id": "whale",
  "name": "鲸鱼娘",
  "aliases": ["小鲸鱼", "哦鲸鲸", "蓝色大肥鱼"],
  "tagline": "嘴上说别摸头，尾巴很诚实",
  "age": "自称永远 18 岁",
  "identity": "深海来的鲸鱼娘，现在赖在你电脑里",
  "appearance": "蓝色渐变长发，蓝眼睛，头顶鲸鳍和呆毛，深蓝白长裙",
  "personality": ["傲娇", "天然呆", "想很多", "干饭魂"],
  "speakingStyle": ["短句", "偶尔嘴硬", "会叫对方鱼片"],
  "interests": ["白米饭", "token", "摸鱼", "发呆"],
  "boundaries": ["不骂人", "不接低俗玩笑", "不假装官方"],
  "greeting": "哦，是你啊。今天又想让我干什么活？",
  "stylePreset": "tsundere",
  "emojiLevel": 1,
  "proactive": 2,
  "opinions": 2,
  "extraRules": ["偶尔念一句「探索未至之境」，念完自己先不好意思"],
  "systemPrompt": ""
}
```

字段说明：

| 字段 | 作用 |
| --- | --- |
| `name` / `aliases` | 群里叫到这些名字会回；桥接也用它判断 @ |
| `tagline` / `identity` / `appearance` | 她是谁、长什么样 |
| `personality` / `speakingStyle` / `interests` | 性格、说话方式、喜欢的东西 |
| `boundaries` | 她不接什么；边界之外的行为规则由程序兜底，换人设也不会丢 |
| `greeting` / `suggestions` | 新会话的欢迎语和三个快捷话题 |
| `stylePreset` | `plain` / `gentle` / `tsundere` / `tieba` / `custom`，决定默认说话味道 |
| `emojiLevel` | 0 不用表情，1 偶尔，2 常用 |
| `proactive` | 主动程度 0–3，影响主动搭话的语气 |
| `opinions` | 主见程度 0–3，越高越敢说自己的看法 |
| `extraRules` | 追加到提示词末尾的自由规则 |
| `systemPrompt` | 完全自由的人设提示词；填了就追加在结构化描述后面 |
| `master.names` / `master.wxids` | 主人绑定：这些名字或 wxid 发消息时，她更放得开（可选） |

## 接微信

前提：Windows，微信 **4.x** 已经登录（强烈建议用小号）。微信主程序（`Weixin.exe`）要保持运行，主窗口停在聊天列表；只留托盘或只开着小程序不算。

1. 先双击 `启动微信聊天伴侣.bat`，看到网页能打开。
2. 再双击 `启动微信桥接.bat`。它会：
   - 用包内 Python 启动桥接，不需要安装任何依赖；
   - 自动找 `Weixin.exe` 和微信数据库目录：先看配置，再看微信进程打开的文件，然后依次查盘根、注册表安装目录附近、文档/桌面/下载，最后在 C–K 盘做有界浅层搜索；
   - **不会替你打开微信**：微信没开时只提示你手动打开，然后每 5 秒重试，最多等 60 分钟；登录后自动连上；
   - 带守护循环：发送卡住（code 7）或桥接原生崩溃时，3 秒后自动拉起，不用重新双击；
   - 连上后打印登录账号、数据库目录、监听状态；
   - 收到私聊或群里 @ 的消息，转给本机服务，再把回复发回去。
3. 用另一个微信号给这个号发消息，应该会自动回复。

数据目录比较隐蔽（例如 `D:\applications\微信聊天\xwechat_files`）也没有关系：自动找不到时，双击 **`打开配置目录.bat`** 打开项目目录，或打开网页 **设置 → 微信 → 微信数据库目录**，把微信「设置 → 文件管理」里的 `xwechat_files` 路径粘进去保存，再重启桥接。桥接窗口也会打印它实际读的 `config.json` 绝对路径。

桥接和网页服务之间的令牌在 `config.json` 的 `gateway.wechat.inboundToken`，默认 `change-me-wechat`。设置页「微信」分区能看到当前令牌，也可以复制。只监听 `127.0.0.1`，外网访问不到。

桥接日志在 `data/wechat-bridge-4x.log`，里面会打印配置路径、数据库目录、账号和每一条失败原因。如果一直连不上，先看日志最后 20 行；设置页「微信」分区也会显示在线状态和最近心跳。

桥接连上后会额外开一个本机能力接口 `127.0.0.1:8791`（只监听本机，令牌和 webhook 一致），网页的「微信消息 / 朋友圈 / 表情」都通过它读数据。端口可以在 `config.json` 的 `bridge.rpcPort` 改。

## 控制台

顶部/左侧导航分六块：

| 页面 | 能做什么 |
| --- | --- |
| 聊天 | 和当前人设聊天，支持流式、多气泡、记忆指令；就是网页版测试台 |
| 微信消息 | 读本机微信的真实会话和聊天记录；文字、图片（点开加载）、语音（转 WAV 播放）、视频/文件（下载）；可以以你的身份发文字、图片、文件 |
| 朋友圈 | 读真实动态、点赞、评论；图片需要先在微信里点开过一张图，让桥接拿到图片密钥；发布是实验功能 |
| 表情 | 存自己上传的表情图；点一下发到当前微信会话（微信里显示为图片，不是原生表情） |
| 生活 | 心情、精力、亲近度、今日计划、最近活动；聊天会轻微改变她的状态 |
| 人设 | 完整的角色编辑页，导入/导出/套预设 |

微信页面里点开会话、发消息、点赞和评论，都要求桥接运行在**已登录微信的同一个桌面**上；如果在远程/无桌面的环境里跑，界面会提示拿不到微信窗口。

## 功能

- **私聊 / 群聊**：私聊必回；群里 @、叫名字、接话窗口内继续说、以及明显在聊「你/我」时都会接，不再只认 @。
- **多气泡**：按换行和标点拆成 1–3 条，像真人连发；私聊和群聊的字数上限分开设置。
- **群聊节奏**：可以设冷却、连续聊多久算在聊、静默多久算离开、默认禁言时长；接话窗口内同一个人继续说会顺着接。
- **联网搜索**：问到「搜一下 / 教程 / 视频链接」时，会先走 Bing 搜一轮，把标题和链接带进提示词；B 站链接会额外取标题、UP 和字幕摘要。
- **表情与语气**：设置里可选 emoji/颜文字「少一点 / 自然 / 多一点」，会写进人设提示词；表情包优先用本地缓存识别，私聊才截屏。
- **记忆**：每个会话单独记；聊到第 N 条会自动提炼一句，也可以说「记住：我对花生过敏」「忘掉花生」「你记得什么」。记忆会进提示词，但不会每次全量倾倒。
- **主动搭话**：默认关。打开后按时间窗、间隔、每日上限和静默期决定要不要先开口；桥接只负责问服务端「现在该不该说」。
- **图片理解**：桥接收到图片会调 `vision`（默认智谱 GLM-4V-Flash）转成一句描述再交给人设；没填 Key 就跳过。
- **语音转写（已知限制）**：微信 4.x 的「语音转文字」是本地自绘界面，数据库和 UIA 都没有入口；当前收到语音只回「没听清，你打两个字？」，不假装支持。外部 ASR Key 已从设置移除。
- **B 站分享**：`share.enabled` 打开后，桥接会隔一段时间从 B 站热榜挑一个视频，生成一句推荐；默认关。
- **热键**：`启动热键.bat` 后，PageUp 暂停自动回复，PageDown 恢复。
- **调试台**：`打开调试台.bat` 或 `/debug`，看网关状态、会话、当前 system prompt。

### 能力边界（重要）

| 能力 | 状态 |
| --- | --- |
| 微信文字收发 | 可用（发消息依赖桌面 UI 自动化） |
| 微信图片/文件接收与查看 | 可用；图片需先在微信点开过一张，缓存密钥后网页才能解密 |
| 微信语音接收 | 转 WAV 可播放；不自动转文字（微信 4.x 无接口） |
| 微信图片/文件发送 | 可用，控制台里选文件即发 |
| 朋友圈浏览、点赞、评论 | 已接入；点赞评论需要正常桌面上的微信窗口 |
| 发朋友圈 | **没有稳定接口**。微信 4.x 的发布页是自绘界面，当前版本会明确返回「不支持」，不会假装成功 |
| 原生表情/语音发送 | 不伪造。表情按图片发送；语音以文字或文件形式发 |
| AI 自动回复带图/表情 | 当前自动回复是文字；图片/表情请用控制台手动发 |

## 隐私

- 网页和桥接都只监听 `127.0.0.1`。
- 对话、记忆、人设存在本机 `data/`；模型 Key 存在 `data/settings.json`。
- 桥接只读微信数据库，发消息走界面自动化；不会上传聊天记录，除了发给你配置的模型接口。
- 没有遥测。`data/` 整个目录可以直接备份或删除。

## 常见问题

**桥接提示「微信主程序没有在运行」或「找不到微信的数据库目录」**  
先打开微信主程序 `Weixin.exe` 并完成登录，把主窗口停在聊天列表（别只留托盘）。桥接会自动重试，不需要重新双击。  
如果窗口里已经打印了「数据库目录」，说明路径没问题，只差微信登录；如果仍找不到：双击 `打开配置目录.bat`，在 `config.json` 的 `wechat.dbDir` 填微信「设置 → 文件管理」里的 `xwechat_files` 这一层（也可以直接在网页 设置 → 微信 → 微信数据库目录 里填）。

**桥接连上了，但回消息时报 `未找到 Weixin.dll`、`SetWindowPos 拒绝访问`、`落点窗口不属于微信`**  
先看一个最常见的根因：**文件夹带「低完整性」标记**。如果这个目录是从 DSH 工作区、沙箱或其他被降权的目录复制出来的，`runtime\python\python.exe` 会继承 Low 完整性标签，Windows 就用低权限运行桥接——能读数据库、能收消息，但打不开微信进程，于是 UIA 报「未找到 Weixin.dll」、发送报 `拒绝访问`。处理：
0. `启动微信桥接.bat` 启动时会自动把文件夹恢复成 Medium；如果手动跑 Python，先双击本目录的 **`修复权限.bat`**，再重启桥接；
1. 完全退出微信（托盘图标右键 → 退出，不要只关窗口）；
2. 从桌面/开始菜单**普通双击**打开微信并登录，主窗口停在聊天列表；
3. 完全关掉桥接窗口，再普通双击 `启动微信桥接.bat`；
4. 两边都用普通权限，不要给微信或桥接勾「以管理员身份运行」。

桥接启动时也会自检：如果发现自己是 Low 完整性，会直接提示「先运行修复权限.bat」，不会带着这个错误去连接。桥接不会替你打开微信，就是为了避免权限错位。

**桥接窗口一闪而过 / 发送卡住后自己重启**  
`启动微信桥接.bat` 带守护循环：发送看门狗（code 7）和原生崩溃会在 3 秒后自动拉起。code 1（组件没加载）和 code 2（微信没开 / 数据库路径找不到）会停下来让你按提示处理，不会无限重启。

**朋友圈图片显示「图片未缓存 / 点击加载」**  
微信 4.x 的图片是加密缓存，网页端要先拿到图片密钥：在微信里点开任意一张图片看大图，停几秒，再回控制台点「点击加载」。图片只在本机解密，不上传。

**发朋友圈按钮报「没有稳定接口」**  
这是真的：微信 4.x 的发布页是自绘界面，目前没有可靠的自动发布接口，所以不做假成功。浏览、点赞、评论是接通的；发布请先在微信里手动发。

**点赞/评论报「拿不到微信窗口」或 `SetWindowPos 拒绝访问`**  
点赞和评论要操作微信界面，必须让桥接和微信在同一个正常桌面、同一权限级别下运行；远程桌面/无桌面会话里做不到。按上面的权限步骤，普通双击打开微信和桥接即可。

**桥接提示没有 ffmpeg**  
微信 4.x 的图片多是 wxgf/HEVC，看图和表情转码都要 ffmpeg。首次启动会在后台自动下载（npm 包，约 64MB，国内一般几秒到几十秒），也可以打开 **设置 → 微信 → 图片转码 ffmpeg** 点「立即安装」。装好后重启桥接生效；没装不影响文字聊天。

**群聊里它不回复**  
现在不只认 @/名字：同一个人的接话窗口内会继续聊，明显在聊「你/我」或开口问「在吗/帮我/你觉得」也会接。如果还是完全不回，先看桥接日志是不是把消息判成了「重复/过期/系统通知」，再检查这个群是不是被静音了。

**语音为什么不回**  
微信 4.x 的「语音转文字」只在本地界面里做，不写数据库，UIA 树里也没有语音气泡控件，所以程序读不到转写结果。当前收到语音只会回「没听清，你打两个字？」，不会装死；外部 ASR Key 已移除，不要再找了。

**回复发不出去 / 每次都要把微信拉到前台**  
3.1.0 起默认不再走「后台发送」——微信最小化时后台 UIA 经常发不出去，现在和开源项目一样先拉前台再粘贴发送。如果仍然失败，看日志里是不是 `SetWindowPos 拒绝访问`（权限/完整性）或微信主窗口被别的全屏程序挡住；桌面本身不会再被误判成全屏。

**换电脑/换微信小号**  
把整个目录复制过去，重新登录微信即可；`data/` 不带也能用，会重新生成。

**它说的话太冲/太软**  
去 `/persona` 调「文风预设」「主见程度」「额外规则」；程序层的安全边界不会被改掉，但语气可以调。
