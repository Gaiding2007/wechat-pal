## 剪辑规则

- 元素吸附 48px 网格；入场 0.2–0.3s 快出+轻微回弹，不做慢速漂浮。
- 每次切镜由一个 UI 元素展开/收起完成，不用纯淡入淡出。
- 强调色只有荧光绿 `#B7F34A`；字幕是底部半透明胶囊，带荧光绿说话点。
- 旁白甜、短句；BGM 旁白时自动 ducking，句间恢复。
- 隐私：只保留群聊名；私聊对象名统一「微信好友」，头像「友」，朋友圈作者/评论全部替换。
