## 剪辑规则（按 Dark Tech Keynote）

- 画面元素全部吸附 48px 网格；入场用 0.2–0.3s 的快出+轻微回弹，不做慢速漂浮。
- 每次切镜都由一个 UI 元素展开/收起完成，不用纯淡入淡出。
- 强调色只有荧光绿 `#B7F34A`；问题/警告色不出现。
- 字幕是底部居中的半透明胶囊，带一个荧光绿「说话」点；每屏最多两行。
- 旁白甜、短句、句尾轻；音乐压在人声下约 8 dB，转场用一声轻 ping 标记。
- 隐私：只保留「团建加载中 / 相亲相爱de一家人 / 测试 / 微信ClawBot」这类群聊名；私聊对象名统一「微信好友」，头像「友」，朋友圈作者/评论全部替换。
